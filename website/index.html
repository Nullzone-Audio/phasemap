How to read it

Centre is safe. The edge is gone in mono.

In Phase mode every horizontal bar is one frequency band, 20 Hz at the bottom and 20 kHz at the top. A bar's width tells you how far that band is from perfect phase, no matter how loud it is.

+1Centre. Identical in both channels, plays fully in mono.
+0.3 … +1Green. Stable stereo.
0 … +0.3Yellow. Wide; partly lost in mono.
below 0Red. Cancels when summed.
−1Edge. Fully out of phase, silent in mono.
Features

Everything at the end of the channel, in one window.

Energy per band

The level of L to the left and R to the right, per frequency band. A lopsided shape shows which part of the mix leans to one side.

Loudness after EBU R128

Momentary, short-term, integrated, loudness range and true peak, with a target line for the platform you deliver to.

Goniometer and balance

The classic picture of the stereo field and the overall L/R level difference, next to the band details.

Correlation with memory

The overall correlation as LEDs. A white marker holds the lowest value for as long as you set, in milliseconds.

Help where you look

Rest the mouse on any control for three seconds and a short explanation fades in. No manual needed.

Sized for your screen

Drag the window from 50 % to 400 %, or fit it to a second monitor. Mono button to listen to the sum, Freeze to stop the display.

Loudness targets

Know when the master is ready.

Choose where your music is going. Integrated turns green on target, yellow when too quiet and red when too loud. True peak turns red above the limit.

Your own targets are saved for every project. The target travels with the session, so a mix opened on another computer still shows the right goal.

GitHub repository How to contribute 
# build and test it yourself (CMake 3.22+, C++17)
git clone https://github.com/nullzone-audio/phasemap.git
cd phasemap
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release

# 100% tests passed, 0 tests failed out of 3

Good first contributions: a new loudness target, a clearer help text, a translation, or testing Phasemap in your DAW and reporting what you find.

Questions

Good to know.

macOS says the plugin is damaged or from an unidentified developer.

The builds are not yet signed with an Apple developer certificate. After copying, run this once in Terminal (adjust the path for VST3 or CLAP):

sudo xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/Components/Phasemap.component
Does Phasemap change my audio?

No. Audio passes through bit for bit, with no latency. Only the Mono button changes what you hear, by summing L and R for as long as it is on.

Which DAWs work?

Any host that loads VST3, AU, CLAP or LV2: Logic Pro, Ableton Live, Cubase, Reaper, Bitwig, Studio One, FL Studio, DaVinci Resolve (Fairlight, VST3) and more, on mono and stereo tracks at any sample rate. Pro Tools needs the AAX format, which Phasemap does not offer yet.

Why does Integrated keep running when the window is closed?

Loudness is measured in the audio engine, so a whole song or episode is measured even if you never open the window. Press Reset, or turn on "Reset Integrated when playback starts" in the settings.

Where are the settings?

Click the word PHASEMAP in the top right corner of the plugin: band resolution, window size, loudness targets and your own saved targets.

Is it really free? What is the catch?

There is none. Phasemap is GPLv3 open source and will stay free. Nullzone is a small open project; if it helps you, the best payment is a bug report, a contribution or telling a friend.
