# Changelog

## 1.0.0 - unreleased

First open-source release (formerly a private tool called "Correlation Meter").

- Phase correlation and energy per frequency band (1/3, 1/6, 1/12 octave), Low End alarm
- Loudness after ITU-R BS.1770-4 / EBU R128: Momentary, Short-term, Integrated, LRA, True Peak
- Built-in delivery targets and user targets
- Correlation meter with adjustable minimum hold, goniometer, balance, Mono Check, Freeze
- Hover explanations, scalable window up to 4K
- VST3, AU, CLAP, LV2, Standalone on macOS, Windows, Linux; mono and stereo
