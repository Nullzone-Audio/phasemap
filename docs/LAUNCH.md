# Launch checklist

## Before going online
- [ ] Fill in Impressum and Datenschutz (name, address, phone) in `website/`
- [ ] Email forwarding hello@nullzone-audio.org (Cloudflare Email Routing)
- [ ] Upload website to Cloudflare Pages, connect nullzone-audio.org
- [ ] Create GitHub organisation `nullzone-audio`, push the repo, first CI run
- [ ] First release `v1.0.0` (tag), test the downloads on macOS / Windows / Linux
